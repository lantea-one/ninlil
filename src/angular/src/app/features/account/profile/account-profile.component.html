Your avatar is looked up from Gravatar, keyed on an MD5 hash of your account's own e-mail address ({{ profile()?.email }}) -- so if that address is ever changed, your avatar changes with it automatically, the next time this page loads. If no Gravatar is registered for that address -- or this server has no path to the internet at all -- your initials are shown instead. This lookup happens entirely in your own browser; your e-mail address itself is never sent anywhere by this server to make it work, only its hash, computed locally before ever leaving your browser.

A bare address (for example 192.168.1.10) is treated as a single-host /32 network.

Grants

There is no separate "deny" rule -- every rule is purely a grant. If a client's address falls inside more than one enabled rule's network, its capabilities are the union of every matching rule's grants, not whichever rule is "most specific" or was created first -- rule order and network overlap never matter to the outcome. A capability granted by two overlapping rules is only actually withdrawn from that client once every rule granting it there is disabled, narrowed, or deleted; disabling just one still-overlapping rule leaves the capability in effect.

A matching client may use this server's recursive resolver even while it is globally disabled.

A matching client's own queries are never subject to rate limiting.

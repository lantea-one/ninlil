Backup & Restore

Create a backup

Downloads an archive of every zone, record, key, credential, user, role, and every other configuration or identity entity this server persists, plus the Data Protection key ring, the shared TLS certificate, and the runtime configuration file. Set a passphrase to encrypt it -- this server never stores it anywhere, so losing it means losing the ability to ever decrypt this archive again, and keeping it somewhere safe is entirely your own responsibility. A passphrase is optional, but leaving it blank is ill-advised: see the warning below.

Deliberately excluded: the persistent query log, the zone-transfer journal, and server logs/metrics. All three are diagnostic history, not configuration -- nothing needed for this server to work again after a restore -- and can grow far larger than everything else in this archive combined.
